# Plan 4.2: Proctor Client Composable, Route Protection, and Card Swipe Parser

## Objective

Build client-side infrastructure for testing center proctors, including route protection middleware, a specialized card swipe parser that strips magnetic stripe sentinels, and a reactive `useCbtfProctor` composable managing live feeds, on-duty state, and check-in/out workflows.

## Context

- `.gsd/SPEC.md`
- `.gsd/DECISIONS.md` (`[DECISION-005]`)
- `app/middleware/admin-only.ts` (reference for role guard)
- `app/composables/features/admin/useCbtfAdmin.ts`

<task type="auto">
  <name>Task 2: Implement card swipe parser and useCbtfProctor composable</name>
  <files>
    app/utils/cardSwipe.ts
    app/composables/features/proctor/useCbtfProctor.ts
  </files>
  <action>
    1. Create `app/utils/cardSwipe.ts`:
       - Function `parseCardSwipe(rawInput: string): string`:
         - Handles standard Track 2 / Track 1 / Track 3 magnetic stripe strings (e.g. `;906000001=...` or `%B906000001^...`).
         - Strips leading sentinels (`;`, `%`, `%B`), extracts student ID before field separator (`=` or `^`), and strips trailing sentinels (`?`).
         - If plain number/alphanumeric entered, trims whitespace and returns as-is.
    2. Create `app/composables/features/proctor/useCbtfProctor.ts`:
       - State:
         - `isOnDuty`: ref boolean synced with `/api/proctor/status`.
         - `feedData`: reactive query fetching `/api/proctor/feed` with auto-polling timer every 15 seconds.
         - `lookupResult`: ref for current student verification preview.
         - `lookupLoading`: ref boolean.
         - `actionLoading`: ref boolean.
         - `lastAction`: ref storing last completed action message (*"Checked in Jane Doe — Retain student ID"* or *"Checked out John Smith — Return student ID"*).
       - Methods:
         - `toggleDuty(status: boolean)`
         - `lookupStudent(rawSwipeOrId: string)`
         - `confirmCheckIn(reservationId: string)`
         - `confirmCheckOut(reservationId: string)`
         - `clearLookup()`
  </action>
  <verify>
    docker compose exec app-dev pnpm vitest run test/unit/app/composables/useCbtfProctor.spec.ts
  </verify>
  <done>
    Card swipe parser accurately isolates student ID numbers, and useCbtfProctor manages live polling, duty status, and check-in/out workflows.
  </done>
</task>
