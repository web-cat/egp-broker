# Plan 4.3: Proctor Command Center Interface (`/proctor`)

## Objective

Build the live single-screen operations command center (`app/pages/proctor/index.vue`) with an auto-focused card swipe action station, visual student photo verification, live seated workstation roster with countdown timers, arriving feed, and departures feed.

## Context

- `.gsd/SPEC.md`
- `.gsd/DECISIONS.md` (`[DECISION-005]`)
- `app/composables/features/proctor/useCbtfProctor.ts`
- `app/components/base/BaseCard.vue`
- `app/components/base/BaseDataTable.vue`

## Tasks

<task type="auto">
  <name>Task 1: Build the Proctor Command Center page (/proctor)</name>
  <files>
    app/pages/proctor/index.vue
  </files>
  <action>
    Create `app/pages/proctor/index.vue` with Option A single-screen layout:
    1. **Top Header**:
       - Testing center name, live digital clock (updating every second).
       - Proctor on-duty toggle switch (`USwitch` with "On Duty" / "Off Duty" badge).
       - Live KPI counters:
         - Currently Seated (e.g. `12 / 48 Seats`).
         - Expected Arrivals in current window.
         - Scheduled to Depart soon.
    2. **Left Column (Swipe Action Station)**:
       - Auto-focused text input for card swipe / barcode scanner.
       - Automatic swipe detection on `Enter` key.
       - Student Verification Card:
         - Student avatar/photo (large, high-visibility).
         - Student full name and institutional Student ID.
         - Assignment title.
         - Workstation seat assignment badge (bold, high-contrast, e.g. `Seat #14`).
         - Status badge and prompt:
           - On Check-In: Green highlight with message: *"Photo matches ID? Direct student to Seat #X. Retain student ID while testing."*
           - On Check-Out: Blue highlight with message: *"Exam complete. Return student ID to student."*
           - On Early/Late Warning: Orange alert with lead/grace tolerance details.
           - On Mismatch / No Reservation: Red error alert with explanation.
         - Instant primary action button (`Confirm Check-In` or `Confirm Check-Out`) with hotkey support (e.g. `Enter` to confirm).
    3. **Right Column (Live Feeds & Seated Roster)**:
       - Tabs / Sections:
         - **Currently Seated Roster**:
           - Workstation seat number, student name, student ID, exam title, elapsed time, and countdown of remaining time in session.
           - 1-click "Check Out" action button per seated row.
         - **Expected Arrivals**:
           - Students scheduled for current/upcoming slot who haven't arrived yet.
           - Scheduled start time, seat number, student name.
         - **Departures Feed**:
           - Students near 60-minute window or checked out in last 30 minutes.
  </action>
