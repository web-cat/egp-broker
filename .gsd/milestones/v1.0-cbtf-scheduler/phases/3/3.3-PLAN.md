# Plan 3.3: Admin CBTF Facility Management Console & Server Endpoints

## Objective

Build the comprehensive administrator management console for the Computer-Based Testing Facility at `/admin/cbtf`, backed by secure administrative endpoints under `/api/admin/cbtf/*`. Provide full CRUD control over facility parameters (total seats, sequential seat allocation order), weekly recurring operating hours, schedule exceptions, proctor shifts, and the global reservations audit log.

- `.gsd/SPEC.md`
- `.gsd/REQUIREMENTS.md` (REQ-01, REQ-02, REQ-14, REQ-15)
- `.gsd/DECISIONS.md` (DECISION-004)

- `app/pages/admin/index.vue`

  <action>
    Implement secure admin endpoints enforcing `requireUserSession` with `globalRole === 'ADMIN'`:
    1. `GET /api/admin/cbtf/facility` & `PATCH /api/admin/cbtf/facility`: Fetch and update facility capacity and seat allocation order sequence.
    2. `POST /api/admin/cbtf/operating-hours` & `DELETE /api/admin/cbtf/operating-hours/:id`: Upsert and delete weekly schedule entries.
    3. `POST /api/admin/cbtf/exceptions` & `DELETE /api/admin/cbtf/exceptions/:id`: Add and remove schedule exceptions (holiday closures, shortened days).
    4. `GET /api/admin/cbtf/shifts`, `POST /api/admin/cbtf/shifts`, & `DELETE /api/admin/cbtf/shifts/:id`: Manage proctor shift schedule.
    5. `GET /api/admin/cbtf/reservations` & `PATCH /api/admin/cbtf/reservations/:id`: View all bookings system-wide with status filtering and administrative updates.
  </action>
  <verify>docker compose exec app-dev pnpm vitest run test/unit/server/api/admin/cbtf.test.ts</verify>
