<objective>

Backed by comprehensive unit tests.

Purpose: Guarantee external tools receive student extensions in sync with pass redemptions, ensuring students never lose passes when external tools fail.

<task type="auto">
  <name>Integrate PassPort extension dispatch, fail-fast error handling, and rollback into server/utils/redemptions.ts</name>
  <files>server/utils/redemptions.ts</files>
  <action>
    Update `server/utils/redemptions.ts`:
    1. Update assignment query in `redeemPass` to include `tool: true`, `course: { include: { platform: true } }`:
       - Retrieve the associated `LtiTool` (if any), course platform, and enrollment context.
    2. PassPort pre-check:
       - If `assignment.tool?.supportsPassport`:
         - Verify `assignment.tool.passportRegistrationStatus === 'REGISTERED'` and valid `passportExtensionUrl` / `passportClientSecret`.
         - If tool is not ready/registered, fail-fast with `502 Bad Gateway` ("External tool is not registered for PassPort extensions. Please contact your instructor.") and send admin alert.
    3. Construct and Dispatch Extension:
       - Fetch student enrollment / user details for property resolution.
       - Call `buildPassPortExtensionPayload`:
         - Context: `lms_instance_guid` (platform issuer or guid), `issuer`, `lti_context_id` (course.sisCourseId or course.id), optional `canvas_course_id`, `lti_deployment_id`.
         - User: `lti_user_id` (enrollment or user.id), optional `broker_user_id`, `email`, `first_name`, `last_name`, `display_name`, `canvas_user_id`.
         - Resource: `lti_resource_link_id` (assignment.resourceLinkId or assignment.id), optional `broker_assignment_id`, `canvas_assignment_id`, `title`.
         - Extension: `pass_type` (pool.passType.name), `original_due_date` (effectiveDates.dueDate ISO), `new_due_date` (extension.newDueDate ISO), `applied_at` (now ISO).
         - `requestedProperties`: `assignment.tool.passportRequestedProperties`.
       - Before transaction commit / balance decrement, call `sendPassPortExtension(assignment.tool, payload)`:
         - Wrap in try/catch:
           - On error:
             - Call `notifyPassPortSyncFailure(...)` with tool name, student details, assignment title, course label, error message, and `payload.request_id`.
             - Abort redemption (throw `createError({ statusCode: 502, statusMessage: 'External tool extension sync failed. Please contact your instructor for assistance.' })`).
             - No pass balance is deducted from pool.
    4. Downstream failure recovery:
       - If any error occurs after `sendPassPortExtension` succeeds before function returns (e.g. during database transaction commit or LMS sync), catch error and call `sendPassPortRollback(assignment.tool, payload.request_id)` asynchronously to maintain state parity with the external tool.
  </action>
  <verify>grep -q "sendPassPortExtension" server/utils/redemptions.ts && grep -q "sendPassPortRollback" server/utils/redemptions.ts</verify>
  <done>PassPort extension dispatch, fail-fast abort, and rollback integrated into pass redemption.</done>
</task>
