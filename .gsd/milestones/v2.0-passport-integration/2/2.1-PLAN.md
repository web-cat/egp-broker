<task type="auto">
  <name>Create PassPort registration orchestration utilities</name>
  <files>server/utils/passport.ts</files>
  <action>
    Create `server/utils/passport.ts`:
    1. `initiatePassPortRegistration(toolId: string, event: H3Event)`:
       - Fetch tool by `toolId` using Prisma.
       - Validate tool exists; throw 404 if not found.
       - Validate tool has `passportRegistrationUrl`; throw 400 if missing.
       - Generate unique secure `registrationToken` using `randomUUID()`.
       - Update tool: `passportRegistrationStatus = 'PENDING'`, `passportRegistrationToken = registrationToken`, `passportRegistrationError = null`.
       - Build Phase 1 payload:
         - `broker_base_url`: resolve via `getServerSiteUrl(event)`.
         - `callback_url`: `${siteUrl}/api/passport/v1/credentials?token=${registrationToken}`.
         - `name`: 'EGP Broker'.
         - `passport_version`: '1.0'.
       - Dispatch POST to `tool.passportRegistrationUrl` using `$fetch`:
         - Set 10-second timeout.
         - On HTTP error or network failure:
           - Update tool: `passportRegistrationStatus = 'FAILED'`, `passportRegistrationError = error.message`.
           - Throw formatted H3 error (502 Bad Gateway with diagnostic message).
       - On success (200-299 / 202 Accepted):
         - Return mapped `ToolRow`.
    2. `handlePassPortCredentialsDelivery(token: string, body: unknown)`:
       - If `!token`, throw 400 'Registration token is required'.
       - Validate `body` using `passPortPhase2CredentialsSchema.parse(body)`.
       - Find tool by `passportRegistrationToken: token`.
       - If not found or status is not `PENDING`, throw 404 'Invalid or expired registration token'.
       - Update tool:
         - `passportClientId: body.credentials.client_id`
         - `passportClientSecret: body.credentials.client_secret`
         - `passportExtensionUrl: body.endpoints.extension_handler`
         - `passportRequestedProperties: body.requested_properties || []`
         - `passportRegistrationStatus: 'REGISTERED'`
         - `passportRegistrationError: null`
         - `passportRegisteredAt: new Date()`
         - `passportRegistrationToken: null`
       - Return mapped `ToolRow`.
    AVOID: Exposing client secrets in logs or responses.
  </action>
  <verify>grep -q "initiatePassPortRegistration" server/utils/passport.ts && grep -q "handlePassPortCredentialsDelivery" server/utils/passport.ts</verify>
  <done>Registration orchestration utilities implemented with robust error handling and token validation.</done>
</task>
