<task type="auto">
  <name>Create shared PassPort schemas and update Tool schemas</name>
  <files>shared/models/passport.ts, shared/models/tool.ts</files>
  <action>
    1. Create `shared/models/passport.ts`:
       - `passPortRegistrationStatusSchema`: enum `['NOT_REGISTERED', 'PENDING', 'REGISTERED', 'FAILED']`.
       - `passPortPhase1RequestSchema`: validates `{ broker_base_url, callback_url, name, passport_version: '1.0' }`. Enforce HTTPS or valid URL.
       - `passPortPhase2CredentialsSchema`: validates `{ tool_name, passport_version, endpoints: { extension_handler }, requested_properties: z.array(z.string()).optional(), credentials: { client_id, client_secret } }`.
       - `passPortExtensionPayloadSchema`: validates Section 2.B extension request `{ request_id, context, user, resource, extension }`.
       - `passPortRollbackPayloadSchema`: validates Section 5 rollback payload with `request_id`.
    2. Update `shared/models/tool.ts`:
       - Extend `toolRowSchema` with: `supportsProxy: z.boolean()`, `supportsPassport: z.boolean()`, `passportClientId: z.string().nullable()`, `passportRegistrationUrl: z.string().nullable()`, `passportExtensionUrl: z.string().nullable()`, `passportRegistrationStatus: passPortRegistrationStatusSchema`, `passportRegistrationError: z.string().nullable()`, `passportRegisteredAt: z.string().nullable()`, `passportRequestedProperties: z.array(z.string()).nullable()`.
       - Extend `createToolSchema` and `updateToolSchema` to accept optional `supportsProxy`, `supportsPassport`, `passportClientId`, `passportClientSecret`, `passportRegistrationUrl`, `passportExtensionUrl`, `passportRequestedProperties`.
       - Update `initialToolState` with default `supportsProxy: true`, `supportsPassport: false`, `passportRegistrationStatus: 'NOT_REGISTERED'`.
    AVOID: Exposing raw `passportClientSecret` or proxy `secret` in standard `toolRowSchema` projection to prevent credential leakage.
  </action>
  <verify>grep -q "passPortPhase2CredentialsSchema" shared/models/passport.ts && grep -q "supportsPassport" shared/models/tool.ts</verify>
  <done>Zod validation schemas exist and are properly exported with strict TypeScript types.</done>
</task>
