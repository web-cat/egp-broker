## 1. Executive Summary

Milestone v8.0 introduces first-class support for internal, course-staff-uploaded notices (`StudentAssignmentNotice`) for student assignments, displayed alongside external tool notices on the TA Interview Console (`GtaInterviewConsole.vue`).

Course instructors and teaching assistants can now bulk-upload notices (such as autograder findings, code review flags, manual grading guidance, or academic integrity notes) via CSV, TSV, or JSON. The server automatically maps student identifiers (emails, university student IDs, or user IDs) against enrolled course rosters, performs transactional upserts, and projects notices into the live TA interview feed. Both external tool notices and uploaded course staff notices are independently displayed with clean visual callouts and strictly sanitized against XSS attacks.

---

## 2. Key Architecture & Design Decisions

- **DECISION-022 (`StudentAssignmentNotice` independent of appointment)**: Notices are stored on a dedicated table keyed on `@@unique([assignmentId, studentId])` with reciprocal relations to `Assignment` and `User` (both as student and author). This ensures notices uploaded in bulk prior to scheduling or between rescheduled appointments are never lost when interview reservations change or cancel.
- **Multi-Format Ingestion**: Course staff can upload notices via comma-separated values (CSV), tab-separated values (TSV), JSON arrays of objects, or JSON key-value dictionaries. Delimited parsers handle headers, quoted text, and commas within notice contents.
- **Robust Identifier Resolution**: The batch upload endpoint resolves student identifiers case-insensitively for emails, trimmed for university student IDs, or by direct user ID. Any unmatched identifiers are returned explicitly in the response for transparency without failing the valid rows.
- **Dual Notice Display**: The TA Interview Console presents external tool notices (`submissionStatus.staffNotice`) and internal course notices (`studentAssignmentNotice.notice`) side by side on both the Active Interview panel and the Expected Arrivals queue cards.
- **Defense in Depth XSS Sanitization**: All notices pass through `sanitizeStaffNoticeHtml()` before DOM insertion via `v-html`, stripping scripts, inline event handlers, iframe/object vectors, and JavaScript pseudo-protocol links while preserving safe typography and formatting.

## 3. Implemented Capabilities & Deliverables

### Data Model & Schemas

- `prisma/schema.prisma`: Added `StudentAssignmentNotice` model with `assignmentId`, `studentId`, `notice`, `authorId`, `createdAt`, `updatedAt`, and unique constraint `@@unique([assignmentId, studentId])`.
- Migration `20261112221910_add_student_assignment_notice` generated and applied.
- `shared/schemas/assignment-notice.schema.ts`: Zod schemas and TypeScript interfaces for DTOs, single upsert, batch upload payloads, and batch operation results.

### Server Endpoints & Services

- `POST /api/me/courses/:courseId/assignments/:assignmentId/notices/batch`: Validates course membership (Instructors and TAs permitted), matches student identifiers against enrolled rosters, batch-upserts records in a transaction, and returns created/updated/unmatched summaries.
- `GET /api/me/courses/:courseId/assignments/:assignmentId/notices`: Retrieves all uploaded notices for an assignment with joined student and author profiles.
- `DELETE /api/me/courses/:courseId/assignments/:assignmentId/notices/:studentId`: Deletes a student notice for an assignment.
- `GET /api/me/courses/:courseId/assignments`: Lists course assignments with interview configurations for modal selection.
- `GET /api/me/courses/:courseId/interviews`: Projects `studentAssignmentNotice: { id, notice, updatedAt } | null` onto each reservation object in the feed.

### Frontend Components & Utilities

- `shared/utils/notice-parser.ts`: Delimited and structured notice parser for CSV, TSV, and JSON.
- `app/components/features/gta/StudentAssignmentNoticeModal.vue`: Modal with assignment selector, live input parsing, preview table, batch upload progress, and summary reporting.
- `app/components/features/gta/GtaInterviewConsole.vue`:
  - Added "Upload Notices" action button to header bar.
  - Added `Course Staff Notice` callout on Active Interview card.
  - Added `Course Staff Notice` banner on Expected Arrivals queue cards.
  - Supported dual notice rendering alongside PassPort external tool notices.
