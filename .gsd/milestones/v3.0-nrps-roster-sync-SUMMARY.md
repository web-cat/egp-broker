## 🎯 Executive Summary

Milestone v3.0 introduces end-to-end support for IMS Global / 1EdTech LTI 1.3 **Names and Role Provisioning Services (NRPS v2.0)**. This allows EGP Broker to automatically synchronize the complete course roster, including student section enrollments and roles, without requiring individual user LMS API tokens.

This resolves a critical edge case where students who had section overrides on assignments with no base due date were allowed pass redemptions beyond the extension window because their section enrollment was missing from the local database.

## 📦 Key Deliverables & Changes

### 1. Data Model & Migration

- Added tracking fields to `model Course` in [prisma/schema.prisma](file:///Users/edwards/git/egp-broker/prisma/schema.prisma):
  - `lastRosterSyncAt DateTime?` — Tracks the timestamp of the most recent successful sync to enforce the 24-hour rate limit.
  - `isRosterSyncing Boolean @default(false)` — Concurrency gating lock to prevent duplicate sync executions.
  - `nrpsContextMembershipsUrl String?` — LTI NRPS endpoint claim cached from launch tokens.
- Migration `20260908145211_add_course_roster_sync_fields` applied to the database.

### 2. NRPS Core Service (`server/utils/nrps.ts`)

- Implemented `acquireRosterSyncLock(courseId)` and `releaseRosterSyncLock(courseId)`:
  - Atomic Prisma conditional updates ensuring only one sync can run at a time per course.
  - Stale lock timeout (10 minutes) to auto-recover if a server process terminates unexpectedly.
- Implemented `syncCourseRosterFromNrps(event, courseId)`:
  - Generates signed JWT client assertion (`RS256` signed with platform deployment private key).
  - Exchanges for OAuth2 Bearer token with scope `https://purl.imsglobal.org/spec/lti-nrps/scope/contextmembership.readonly`.
  - Traversing RFC 5988 `Link: <url>; rel="next"` pagination headers to fetch all members.
  - Upserts `CourseSection` records using Canvas section claim extensions.
  - Links/creates `User`, `UserIdentity`, and `Enrollment` (including `courseSectionId`).
  - Sets `lastRosterSyncAt = now()` upon successful sync.

### 3. LTI 1.3 Launch Integration (`server/utils/lti-launch.ts` & `launch.post.ts`)

- Updated Canvas tool registration config with `$Canvas.course.sectionIds` variable substitution.
- Extracted and stored `https://purl.imsglobal.org/spec/lti-nrps/claim/namesroleservice` `context_memberships_url`.
- Evaluated trigger criteria on launch:
  1. Instructor / Admin launch: trigger sync if `lastRosterSyncAt` is `null` or > 24 hours ago.
  2. Student launch: trigger sync if student has no `courseSectionId`.
- If triggered: acquires atomic lock and asynchronously executes `syncCourseRosterFromNrps` in background.
- Appends `?sync=roster` query parameter to redirect URL if sync was triggered OR if a concurrent sync is in progress.

### 4. REST APIs

- `GET /api/me/course/roster-sync-status`: Returns `{ isSyncing: boolean, lastRosterSyncAt: string | null }`.
- `POST /api/me/course/roster-sync`: Allows instructors to manually initiate a roster sync on demand.

### 5. Frontend & UI Experience

- Created [app/components/features/dashboard/RosterSyncModal.vue](file:///Users/edwards/git/egp-broker/app/components/features/dashboard/RosterSyncModal.vue):
  - Non-dismissible modal displaying an animated spinner and progress bar.
  - Polls roster sync status every 1.5 seconds.
  - Transitions to a success checkmark and auto-closes when sync finishes.
- Integrated into [Student.vue](file:///Users/edwards/git/egp-broker/app/components/features/dashboard/Student.vue) and [Teacher.vue](file:///Users/edwards/git/egp-broker/app/components/features/dashboard/Teacher.vue):
  - Shows modal whenever `route.query.sync === 'roster'` or when `isRosterSyncing` is detected.
  - Teacher dashboard displays `Last synced: [date/time]` alongside a manual `Sync Roster` button.
  - Automatically cleans up the query string and refreshes dashboard data (assignments, pass pools, enrollments, sections) when sync finishes.
- Internationalized in English (`en`) and French (`fr`).
