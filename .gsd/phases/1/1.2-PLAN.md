# Plan 1.2: Shared Schemas, Database Seeding & Unit Tests

## Objective

Establish the cross-boundary contracts and data seeding for the CBTF feature. Define Zod validation schemas and TypeScript model interfaces in `shared/`, update the database seed script to populate a default testing facility with weekly operating hours and a test proctor, and implement comprehensive Vitest unit tests.

- `.gsd/SPEC.md`

- `shared/models/assignment.ts`
- `prisma/seed.ts`
