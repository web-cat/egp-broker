# Plan 3.1: Instructor Assignment Configuration for CBTF Scheduling

## Objective

Enable instructors to configure whether an assignment requires a CBTF testing center reservation, set the start and end of the reservation window, and display clear CBTF status indicators on the teacher's dashboard.

## Context

- `.gsd/SPEC.md`
- `.gsd/REQUIREMENTS.md` (REQ-03)
- `.gsd/DECISIONS.md` (DECISION-004)
- `app/components/features/admin/AssignmentEditPanel.vue`
- `app/components/features/dashboard/Teacher.vue`
- `server/api/me/assignments/[id].patch.ts`
- `server/utils/assignments.ts`
