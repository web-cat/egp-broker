# Plan 3.2: Student Dashboard Integration & 4-Step Progressive Narrowing Modal

## Objective

Build the student-facing CBTF reservation experience: a 4-step progressive narrowing stepper modal (`CbtfScheduleModal.vue`), inline status buttons in the student assignments table, an upcoming exam summary card at the top of the dashboard, and a feature composable (`useCbtfStudent.ts`) handling all booking, rescheduling, and cancellation interactions.

## Context

- `.gsd/SPEC.md`
- `.gsd/REQUIREMENTS.md` (REQ-07, REQ-08, REQ-09)
- `.gsd/DECISIONS.md` (DECISION-004)
- `app/components/features/dashboard/Student.vue`
- `app/composables/features/useStudentDashboard.ts`
- `server/api/me/cbtf/availability.get.ts`
- `server/api/me/cbtf/reservations.*.ts`

## Tasks

<task type="auto">
  <name>Create Student CBTF Feature Composable</name>
  <files>app/composables/features/useCbtfStudent.ts</files>
  <action>
    Create `app/composables/features/useCbtfStudent.ts`:
    - `reservations`: reactive fetch of `GET /api/me/cbtf/reservations`.
    - `activeReservations`: computed list of `SCHEDULED` or `CHECKED_IN` reservations.
    - `nextUpcomingReservation`: earliest scheduled reservation in the future.
    - `fetchAvailability(assignmentId, timeOfDayPreference?, selectedDate?)`: calls `GET /api/me/cbtf/availability`.
    - `createReservation(assignmentId, startTime)`: calls `POST /api/me/cbtf/reservations`.
    - `rescheduleReservation(reservationId, newStartTime)`: calls `PATCH /api/me/cbtf/reservations/:id`.
    - `cancelReservation(reservationId)`: calls `DELETE /api/me/cbtf/reservations/:id`.
  </action>
  <verify>docker compose exec app-dev pnpm vitest run test/unit/app/composables/useCbtfStudent.spec.ts</verify>
  <done>Composable cleanly wraps all student CBTF endpoints and state.</done>
</task>

<task type="auto">
  <name>Create Progressive Narrowing Stepper Modal</name>
  <files>app/components/features/cbtf/CbtfScheduleModal.vue</files>
  <action>
    Create `app/components/features/cbtf/CbtfScheduleModal.vue` with:
    1. **Active Reservation View**: If student has a scheduled or missed reservation, display current reservation details (date, time, seat number) with "Reschedule" and "Cancel Reservation" buttons.
    2. **Booking / Rescheduling Wizard (Stepper)**:
       - **Step 1: Time of Day Preference**: Cards for "Morning" (before 12:00 PM) and "Afternoon" (12:00 PM onwards).
       - **Step 2: Recommended Days**: 3–4 day cards showing date, open slots count, and utilization percentage bar.
       - **Step 3: Hourly Slot Selection**: Radio options showing 1 randomly selected open slot per hour on that day.
       - **Step 4: Confirmation**: Review selected slot, duration (60 minutes), notice of sequential seat assignment, and "Confirm Reservation" button. Upon confirmation, show assigned seat number and success message.
    3. Navigation controls (Back, Next, Cancel) and loading states.
  </action>
  <verify>docker compose exec app-dev pnpm vitest run test/unit/app/components/features/cbtf/CbtfScheduleModal.spec.ts</verify>
  <done>Stepper modal guides students through progressive selection and allows rescheduling/canceling.</done>
</task>
