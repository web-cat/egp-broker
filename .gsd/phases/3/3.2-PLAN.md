<task type="auto">
  <name>Enhance ToolEditPanel with dual-role controls and PassPort registration action station</name>
  <files>app/components/features/admin/ToolEditPanel.vue</files>
  <action>
    Update `app/components/features/admin/ToolEditPanel.vue`:
    1. Update `LocalToolState` and initial/sync state watchers:
       - Include `supportsProxy: boolean`, `supportsPassport: boolean`, `passportClientId: string`, `passportClientSecret: string`, `passportRegistrationUrl: string`, `passportExtensionUrl: string`, `passportRegistrationStatus: string`, `passportRegistrationError: string | null`, `passportRegisteredAt: string | null`.
    2. Add Role Selection checkboxes:
       - "Supports LTI Proxy" (`supportsProxy`).
       - "Supports PassPort Extensions" (`supportsPassport`).
    3. Proxy Credentials section (shown when `supportsProxy` is true):
       - `key` (Consumer Key)
       - `secret` (Shared Secret)
    4. PassPort Configuration section (shown when `supportsPassport` is true):
       - `passportRegistrationUrl`: URL where Phase 1 registration is posted.
       - Status & Action Station:
         - Status badge displaying `passportRegistrationStatus` (NOT_REGISTERED, PENDING, REGISTERED, FAILED).
         - Registered timestamp if present.
         - Error alert banner displaying `passportRegistrationError` if failed.
         - "Register with PassPort" action button:
           - Enabled only for saved tools (`isEdit`) with `passportRegistrationUrl`.
           - Shows loading spinner when registration is in progress.
           - Clicking triggers `registerPassPort(props.tool.id)` via `useAdminTools()`.
           - On success: updates local `passportRegistrationStatus` to `PENDING`, emits 'saved' with updated tool data, and displays success toast.
           - On error: updates local status to `FAILED`, displays error toast with failure detail.
       - Advanced/Manual PassPort fields (expandable or clean form inputs):
         - `passportExtensionUrl` (Extension handler URL).
         - `passportClientId` (Client ID).
         - `passportClientSecret` (Client Secret).
    5. Clean submission: ensure all fields map to `CreateToolData` / `UpdateToolData`.
  </action>
  <verify>grep -q "supportsPassport" app/components/features/admin/ToolEditPanel.vue && grep -q "registerPassPort" app/components/features/admin/ToolEditPanel.vue</verify>
