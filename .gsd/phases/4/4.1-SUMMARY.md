# Plan 4.1: PassPort HMAC Signer, Payload Builder, Dispatch Utilities & Alerting — Summary

## Changes Made

1. **`server/utils/passport.ts`**:
   - Implemented `signPassPortRequest(secret, body, timestamp)` generating HMAC-SHA256 hex signatures and Unix timestamps.
   - Implemented `buildPassPortExtensionPayload(params)` constructing compliant payloads conforming to `passPortExtensionPayloadSchema`. Mandatory baseline fields are always populated, and optional properties (e.g. `canvas_course_id`, `email`, `first_name`, `last_name`, `canvas_assignment_id`, `title`) are strictly filtered based on the tool's `requestedProperties`.
   - Implemented `sendPassPortExtension(tool, payload)` dispatching signed POST requests to `passportExtensionUrl` with headers `X-PassPort-Client-ID`, `X-PassPort-Signature`, `X-PassPort-Timestamp`, `Content-Type: application/json` and a 10s timeout.
   - Implemented `sendPassPortRollback(tool, requestId)` dispatching signed DELETE requests to `passportExtensionUrl` with `{ request_id }` and a 10s timeout.

2. **`server/services/alert.service.ts`**:
   - Added `PassPortSyncFailureAlertData` interface.
   - Implemented `notifyPassPortSyncFailure(data)` sending urgent operational admin alerts with student identity, course label, assignment title, external tool name, error message, and request ID via `sendAdminAlert` (priority: `urgent`, tags: `['warning', 'passport', 'rotating_light']`).

3. **`test/unit/server/utils/passport-extension.test.ts`**:
   - Added 10 unit tests verifying HMAC signer, privacy-preserving property filtering, UUID generation, extension dispatch header and payload structure, timeout error handling, and rollback dispatching.

4. **`test/unit/server/services/alert-passport.test.ts`**:
   - Added 3 unit tests verifying formatted urgent alert dispatching, fallback handling for optional fields, and graceful error handling.
