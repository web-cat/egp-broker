<task type="auto">
  <name>Task 2: Implement proctor server utilities in server/utils/cbtf.ts</name>
  <files>
    server/utils/cbtf.ts
  </files>
  <action>
    Implement helper functions in `server/utils/cbtf.ts`:
    - `getProctorLiveFeed(prisma, facilityId)`:
      - Returns:
        - `seated`: All reservations with `status: 'CHECKED_IN'`, calculating `elapsedMinutes` and `remainingMinutes`.
        - `arriving`: Upcoming reservations where `startTime` is between `now - graceMinutes` and `now + leadMinutes + 15m` and status is `SCHEDULED`.
        - `departing`: Seated reservations with $\le 10$ minutes remaining, or recently completed within last 15m.
        - `facility`: total seats, currently seated count, available seats.
    - `lookupStudentForProctor(prisma, studentId)`:
      - Finds user by `studentId` (or institutional ID).
      - Checks if student has an active reservation (`SCHEDULED` or `CHECKED_IN`).
      - Validates check-in window against `facility.checkInLeadMinutes` and `facility.checkInGraceMinutes`.
      - Returns lookup decision (`READY_FOR_CHECKIN`, `EARLY`, `LATE`, `READY_FOR_CHECKOUT`, `NO_RESERVATION`, `ALREADY_CHECKED_OUT`).
    - `checkInReservation(prisma, reservationId, proctorUserId)`:
      - Sets `status = 'CHECKED_IN'`, `checkedInAt = new Date()`, `checkedInByUserId = proctorUserId`.
    - `checkOutReservation(prisma, reservationId, proctorUserId)`:
      - Sets `status = 'CHECKED_OUT'`, `checkedOutAt = new Date()`, `checkedOutByUserId = proctorUserId`.
  </action>
  <verify>
    docker compose exec app-dev pnpm vitest run test/unit/server/utils/cbtf.test.ts
  </verify>
  <done>
    Proctor operations utilities are implemented, handling early/late tolerances and state transitions cleanly.
  </done>
</task>
