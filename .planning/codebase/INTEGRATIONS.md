# INTEGRATIONS.md — External Services & APIs

## LTI 1.3 (Primary Integration)

EGP Broker acts as an **LTI 1.3 Tool** embedded within LMS platforms (primarily Canvas).

### OIDC / LTI Launch Flow

```
1. Platform → GET /api/lti13/login   (OIDC login initiation)
2. Tool      → Redirect to Platform auth endpoint with nonce/state
3. Platform  → POST /api/lti13/launch  (id_token JWT + state)
4. Tool      → Verifies JWT via platform JWKS endpoint
5. Tool      → setUserSession() → redirect to targetLinkUri
```

**Key files:**

- `server/api/lti13/login.get.ts` — OIDC initiation, stores nonce/state in session
- `server/api/lti13/launch.post.ts` — JWT verification, user upsert, session creation
- `server/api/lti13/config.get.ts` — LTI configuration JSON for platform registration
- `server/api/lti13/jwks.get.ts` — Tool's public JWKS endpoint
- `server/utils/lti.ts` — `verifyLtiToken()`, `parseCourseRole()`, `createLtiLoginUrl()`

**Runtime config:** `NUXT_LTI_PRIVATE_KEY` (PKCS8), `NUXT_LTI_KEY_ID`

**LTI Advantage Services configured:**

- AGS (Assignment and Grades Services) — `lineitem` read/write scopes
- NRPS (Names and Role Provisioning Services) — membership read scope
- Placements: `course_navigation`, `assignment_selection`, `link_selection`

**Canvas-specific custom variables captured at launch:**

- `$Canvas.course.id` → `Course.canvasCourseId`
- `$Canvas.course.workflowState` → `Course.workflowState`
- `$Canvas.assignment.id` → `Assignment.canvasAssignmentId`

### Canvas REST API

Used for syncing assignment data from Canvas courses.

**File:** `server/utils/canvas.ts`

```typescript
fetchCanvasAssignments(domain, courseId, accessToken): Promise<CanvasAssignment[]>
```

- Calls `GET https://{domain}/api/v1/courses/{courseId}/assignments`
- Handles pagination via `Link` header (`rel="next"`)
- Requires per-user `platformApiKey` stored on `LtiIdentity`

## CAS (Central Authentication Service)

Supports institutional SSO via CAS 2.0 / 3.0.

**Files:**

- `server/api/cas/login.get.ts` — redirects to CAS login
- `server/api/cas/callback.get.ts` — handles service ticket validation
- `server/api/cas/servers.get.ts` — lists configured CAS servers
- `server/services/cas.service.test.ts` (service layer)

**Database:** `CasServer` model holds `baseUrl` and `serviceValidateVersion`.
**Identity linking:** `CasIdentity` links `User` ↔ `CasServer` via `casUsername`.

## Email (SMTP / Nodemailer)

Used for transactional email: verification, password reset.

**Config (runtime env vars):**

```
NUXT_EMAIL_HOST, NUXT_EMAIL_PORT, NUXT_EMAIL_SECURE
NUXT_EMAIL_USER, NUXT_EMAIL_PASS, NUXT_EMAIL_FROM
```

**File:** `server/utils/email-transporter.helpers.ts`
**Templates:** `server/templates/` (Handlebars `.hbs` files, served as Nitro server assets)

**Emails sent by:**

- `server/api/auth/register.post.ts` — verification email
- `server/api/auth/forgot-password.post.ts` — reset link
- `server/api/auth/resend-verification.post.ts` — resend verification

## Security Notes

- **Frame-ancestors: `*`** — Required for LTI iframe embedding inside Canvas
- **`xFrameOptions: false`** — Same reason
- **`crossOriginEmbedderPolicy: 'unsafe-none'`** — LTI compatibility
- **CORS enabled on `/api/**`** — `Access-Control-Max-Age: 86400`
- **SameSite: `none`** — Required for session cookies in LTI iframes (`getIframeCookieOptions()` in `server/utils/lti.ts`)
